## 세운 가설과 검증 결과
1. 네트워크 지연 — ALB/노드 네트워크 대시보드(RTT, 재전송, 드롭) — 배제 — RTT 0.31→0.33ms, 재전송·드롭 변화 없음
2. payment-gateway 배포(타 팀) — 요청 경로 확인 — 배제 — 주문내역 조회는 결제사를 호출하지 않음, 결제 API 정상
3. WAF 시그니처 업데이트 — ALB 지표 — 배제 — 장애 시작 이후 적용, ELB_5XX 0, 차단이 아닌 지연 증상
4. #1182 정렬 옵션 추가 — 실행계획 — 배제 — 정렬은 ordered_at DESC로 인덱스(MEMBER_NO, ORDERED_AT DESC)가 커버, Predicate에 정렬 관련 문제 없음
5. #1185 memberNo 타입 Long 통일 — V$SQL, DBMS_XPLAN — 확정 — MEMBER_NO는 VARCHAR2(20), 숫자 바인딩으로 TO_NUMBER 묵시적 형변환 발생 → 인덱스 미사용, 4,218만 건 풀스캔

## 근본 원인
v2.14.0의 #1185(OrderSearchCondition 리팩토링)에서 memberNo 자바 타입을 String에서 Long으로 바꿨으나, DB의 ORDERS.MEMBER_NO 컬럼은 VARCHAR2(20)로 그대로였다. Hibernate가 숫자로 바인딩하자 Oracle이 비교를 위해 컬럼 쪽에 TO_NUMBER를 적용했고(묵시적 형변환), 그 결과 인덱스 IDX_ORDERS_MEMBER_ORDERED를 사용하지 못해 매 요청마다 약 4,200만 건 풀스캔이 발생했다.

5 Whys
1. 왜 주문내역 화면이 안 떴나? → 목록 API 응답이 평균 5.8초로 느려지고 커넥션 풀(20개)이 포화되어 대기 요청이 쌓였다.
2. 왜 API가 느려졌나? → 목록 쿼리가 실행당 약 122만 블록을 읽었다(배포 전 38블록). DB CPU 92%, 디스크 읽기 980MB/s.
3. 왜 그렇게 많이 읽었나? → 실행계획이 INDEX RANGE SCAN에서 TABLE ACCESS FULL로 바뀌었다.
4. 왜 실행계획이 바뀌었나? → 숫자 바인딩으로 TO_NUMBER("MEMBER_NO") 묵시적 형변환이 생겨 인덱스를 쓸 수 없었다.
5. 왜 배포 전에 발견하지 못했나? → 자바 타입 변경이 DB 컬럼 타입과 맞는지 검토하는 절차가 없었고, 운영 수준 데이터량에서 실행계획을 확인하는 단계가 배포 전에 없었다.

## 완화 조치와 근본 해결
- 완화: order-api v2.13.2로 롤백 (13:20 실행, 13:24 완료, 13:28 정상화). 스키마 변경이 없어 롤백 호환성 문제 없음 확인 후 진행
- 해결(재배포 시): 쿼리 바인딩 필드는 DB 컬럼에 맞춰 String 유지. 서비스 계층에서 Long이 필요하면 DTO는 Long으로 두고 쿼리 직전 경계에서 한 번만 String으로 변환. 배포 전 스테이징에서 해당 쿼리 실행계획이 INDEX RANGE SCAN인지 확인
- 장기(선택): MEMBER_NO 컬럼 NUMBER 전환은 별도 과제로 분리. 영향 범위(배치, 정산, 타 시스템) 조사와 데이터 검증(앞자리 0, 비숫자 값) 후 계획된 작업으로 진행
- 채택하지 않은 안: TO_NUMBER(MEMBER_NO) 함수 기반 인덱스. 비숫자 값이 들어오면 INSERT 실패 위험이 있어 제외

## 재발 방지
- [ ] 코드 리뷰: 엔티티·검색 조건의 필드 타입 변경 시 DB 컬럼 타입 일치 여부를 리뷰 체크리스트에 추가
- [ ] 테스트/스테이징: 운영 규모 데이터가 있는 스테이징에서 주요 조회 쿼리 실행계획을 배포 전 확인 (TABLE ACCESS FULL 발생 여부)
- [ ] 모니터링: 배포 직후 신규 SQL_ID 중 gets/exec 또는 평균 응답시간이 급증한 SQL을 감지하는 알람 추가
- [ ] 배포 프로세스: 배포 알림을 #alert-prod에도 남겨, 장애 시 자기 서비스 변경점을 알람 목록에서 바로 볼 수 있게 함

## 회고
- 잘한 점: 막힌 시점을 바로 공유함. 초기에 CS팀 "장애 확인 중" 공지를 요청함. 네트워크 가설을 지표로 확인해 배제함. 원인 확정 후 스키마 변경 여부를 보고 롤백을 결정함
